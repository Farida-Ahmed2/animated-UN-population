An animated bar chart race showing the top 10 most populous countries in the world over time, built with matplotlib and UN population data — complete with country flags next to each bar.
What it does

The script reads historical population data,
ranks countries by population for each year,
and animates the top 10 as a horizontal bar chart that updates year by year.
Each bar is labeled with its exact population and paired with the corresponding country's flag, and the current year is displayed on screen.
The final animation is exported as an MP4.
